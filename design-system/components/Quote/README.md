# Quote

A pull quote set large under a `rule`, with its opening mark hanging outside the text edge and the source beneath.

- Markup: `figure.rs-quote` > `blockquote > p` + `figcaption` (`.rs-eyebrow` name, `.rs-t-small` role or source). Consumer provides the quote text (with typographic quotes “ ”), name and source.
- Size steps 28/32 → 32/40 → 40/48 at 640 and 1024. Weight 400 — size, not boldness, makes it a quote.
- In an Article it spans columns 3–10 at ≥1024 and the full width below that.
- Under 40 words. One per section. Never italic, never centred, no decorative quote glyphs beyond the text's own marks.
